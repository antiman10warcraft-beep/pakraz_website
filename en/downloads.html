DOCUMENT CONTROL

Checks before publication or use

Listing a document type here does not mean that the document has been received or approved.

  1. The product name and grade code on the document match the requested item.
  2. The document revision number and date are clear; obsolete revisions are withdrawn.
  3. The document language and intended market are clear.
  4. A COA is linked to a specific batch/lot; a generic document is not a batch COA.

For technical decisions, review the current document for the exact grade. Data from another grade, a generic sheet or a different project is not a substitute.
